# Holodeck SMP Server Migration
This project contains tooling to assist with the migration of the Holodeck SMP server when a new version is not back-wards compatible.  

__________________
Lead developer: Sander Fieten  
Code hosted at https://github.com/holodeck-b2b/smp-server-migration  
Issue tracker https://github.com/holodeck-b2b/smp-server-migration/issues  

## Usage
Documentation on how the tooling provided by this project is to be used when migrating the Holodeck SMP server can be found on [our website](https://holodeck-smp.org/documentation/setting-up-holodeck-smp/upgrading/).

### Submitting bugs
You can report issues directly on the [project Issue Tracker](https://github.com/holodeck-b2b/smp-server-migration/issues).
Please document the steps to reproduce your problem in as much detail as you can (if needed and possible include screenshots).
